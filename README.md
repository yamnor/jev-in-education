## 読むときの注意

- 答えはすべて人工の答えです。AIに下書きさせ、著者が確認しました。実際の学生の答案は含みません。
- 小さな検証の記録です。精度の推定や、成績評価に使えるかどうかの判断には使えません。
- 期待する判定は、Jevに送る前に決めて固定しました。各フォルダの protocol.txt に、送信前の仕様と変更履歴があります。
- モデルの版（例：jev-1.13.0）は各フォルダに明記しています。版が変わると結果も変わることがあります。
- Jevのプライバシーポリシーは18歳未満の個人データを意図的に扱わないとしているため、著者は高校生以下の答案をJevに送らない方針にしています。
